# @bc/web

Interfaz funcional de Verichain. Desde la raíz del repositorio:

```bash
npm run dev -w @bc/web
npm run test -w @bc/web
npm run build -w @bc/web
```

El servidor de desarrollo escucha en `http://127.0.0.1:5173` y envía `/api` a `http://localhost:3000`. La sesión se consulta mediante cookie; las páginas de funcionalidades posteriores muestran marcadores temporales.
