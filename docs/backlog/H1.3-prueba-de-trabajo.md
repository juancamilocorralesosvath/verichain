# H1.3 — Prueba de trabajo (minado)

## Contexto

Diseño §5.5. `hash_cadena` debe empezar con N ceros hex. Por defecto N=4 (la demo debe ser ágil: menos de ~2 s por bloque).

## Archivos

- `packages/core/src/pow.ts`, `packages/core/test/pow.test.ts`

## Especificación

```ts
export function cumpleDificultad(hashHex: string, dificultad: number): boolean; // empieza con `dificultad` ceros
export interface ResultadoMinado {
  nonce: number;
  hashCadena: string;
  intentos: number;
  ms: number;
}
export function minar(
  hashAnterior: string,
  hashDatos: string,
  dificultad: number,
  opciones?: { maxIntentos?: number },
): ResultadoMinado;
```

- Recorre `nonce = 0, 1, 2, ...` hasta que `calcularHashCadena(...)` cumpla la dificultad.
- `maxIntentos` (por defecto 50_000_000): si se supera, lanza error.
- `dificultad` es un entero entre 0 y 8. Fuera de rango, lanza error.
- `ms` se mide con `performance.now()` (existe en Node y en el navegador).

## Criterios de aceptación

- [ ] Con dificultad 0, el nonce es 0.
- [ ] Con dificultad 3, el `hashCadena` resultante empieza con `000` y es igual a `calcularHashCadena(prev, hd, nonce)`.
- [ ] `cumpleDificultad` rechaza un hash con menos ceros.
- [ ] `maxIntentos: 1` con dificultad 6 lanza error.
- [ ] Prueba de tiempo informativa (no falla): imprimir los ms para dificultad 4.
