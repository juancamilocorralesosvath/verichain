# H1.2 — Hashes SHA-256 y bloque génesis

## Contexto

Diseño §4 "Hashes" y el glosario de AGENTS.md. Cubre el requisito central del enunciado: hash de los datos + hash de todos los bloques ("hash de los hashes").

## Objetivo

Funciones puras para `hash_datos`, `hash_cadena` y los datos del génesis.

## Archivos

- `packages/core/src/hash.ts`, `packages/core/src/genesis.ts`
- `packages/core/test/hash.test.ts`
- Dependencia: `npm install -w @bc/core @noble/hashes` (SHA-256 síncrono e isomórfico; prohibido `node:crypto` en core)

## Especificación (no cambiar sin actualizar el diseño)

```ts
export function sha256Hex(texto: string): string; // UTF-8 → hex minúsculas, 64 chars
export function calcularHashDatos(fila: FilaPersona): string; // sha256Hex(serializarPersona(fila))
export function calcularHashCadena(hashAnterior: string, hashDatos: string, nonce: number): string;
//   = sha256Hex(hashAnterior + hashDatos + String(nonce))   (concatenación directa; ambos hashes son 64 hex fijos)
export const HASH_CERO = '0'.repeat(64);
export const DATOS_GENESIS = 'GENESIS';
export const HASH_DATOS_GENESIS: string; // sha256Hex('GENESIS')
```

- `calcularHashCadena` lanza error si `hashAnterior` o `hashDatos` no son 64 hex en minúsculas, o si `nonce` no es un entero >= 0.

## Criterios de aceptación

- [ ] `sha256Hex('abc')` = `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad` (vector oficial NIST).
- [ ] `sha256Hex('')` = `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`.
- [ ] Cambiar un solo carácter de cualquier campo de la fila cambia `calcularHashDatos`.
- [ ] Cambiar `hashAnterior` o `nonce` cambia `calcularHashCadena`.
- [ ] Las entradas inválidas lanzan error.
