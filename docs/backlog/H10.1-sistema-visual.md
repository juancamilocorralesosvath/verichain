# H10.1 — Sistema visual

## Contexto

Diseño §8: el diseño visual es un módulo aparte que reestiliza la interfaz funcional de E9 **sin cambiar su lógica**. Lo puede tomar cualquiera de los dos.

## Especificación

- Elige una estética coherente con el tema: seguridad, integridad, "libro mayor". Usa el skill `frontend-design` si trabajas con Claude.
- Tokens en CSS (variables): colores, tipografía, espaciado, radios. Colores semánticos `--ok`, `--falla`, `--no-aplica` con contraste AA. Monoespaciada para los hashes.
- Componentes base en `apps/web/src/ui/`: Botón, Campo, Tabla, Tarjeta, Insignia de estado, Hash (abrevia, copia al portapapeles, tooltip con el valor completo) y Alerta.
- Tema claro obligatorio. El oscuro es opcional.
- No cambia la API ni la lógica de las páginas: solo marcado y estilos.

## Criterios de aceptación

- [x] Las páginas existentes usan los componentes base.
- [x] El contraste AA de los estados se verifica con una herramienta, y el resultado queda anotado en las notas.
- [x] Las pruebas de E9 siguen pasando sin modificarse (salvo selectores puramente visuales).

## Verificación

```bash
npm run test -w @bc/web && npm run build -w @bc/web && npm run check
```

## Notas de traspaso

### Decisiones tomadas

- Estética "libro mayor": papel gris‑verdoso (`--papel`), tinta azul‑marino, acento azul de sello, tablas con regla de doble línea bajo el encabezado, serif del sistema para títulos y monoespaciada para hashes. Solo fuentes del sistema.
- Todo en `apps/web/src/estilos.css` (tokens en `:root`). **Sin estilos en línea**: la CSP de nginx (H11.2) usa `style-src 'self'`. Quien añada UI nueva no debe usar el atributo `style`.
- Componentes en `src/ui/`: `Boton`, `Campo`, `Tabla`, `Tarjeta`, `Insignia`, `Hash`, `Alerta` (más `index.ts`). Las páginas existentes y `<ReporteVerificacion>` ya los usan; `abreviarHash` se reexporta desde `Cadena.tsx`.
- Los estados nunca van solo con color: icono + texto (`✓ ok`, `✕ falla`, `– no aplica`).
- Tema oscuro: no se hizo (opcional). Se probó a 1280 px y 375 px con la API y la web reales (BD temporal).
- Las 102 pruebas de E9 pasan sin modificarse; se añadieron 6 de los componentes base.
