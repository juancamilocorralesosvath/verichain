# H3.3 — Gestión de usuarios (admin)

## Especificación

- Solo admin:
  - `GET /api/usuarios`
  - `POST /api/usuarios { username, password, rol }`
  - `PATCH /api/usuarios/:id { activo?, rol? }`
- Política de contraseña: mínimo 12 caracteres, que no sea igual al username. Validar en el DTO.
- No se borran usuarios (quedan referenciados en bloques y bitácora): solo se desactivan. Un usuario inactivo no puede iniciar sesión, y si ya tiene un JWT, este se rechaza en la siguiente petición (el guard consulta `activo`).
- Las respuestas **nunca** incluyen `password_hash`.
- Un admin no puede desactivarse a sí mismo ni quitarse el rol de admin.

## Criterios de aceptación

- [ ] e2e: un registrador o auditor que llama a cualquiera de estos endpoints → 403.
- [ ] e2e: contraseña corta → 400.
- [ ] e2e: desactivar un usuario con sesión abierta → su siguiente petición da 401.
- [ ] Ninguna respuesta incluye `password_hash` (prueba).
