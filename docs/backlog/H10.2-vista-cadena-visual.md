# H10.2 — Cadena como bloques conectados y minado animado

## Especificación

- La página Cadena se muestra como bloques conectados (tarjetas unidas por flechas) con: índice, `hash_anterior` → `hash_cadena`, nonce, firmante y estado.
- Después de verificar, cada bloque se colorea por su estado, y la conexión rota se resalta en rojo.
- Al crear un bloque, una animación o indicador de "minando…" muestra el nonce y el tiempo. Los datos vienen de la respuesta de confirmar; si hace falta, la API agrega `{ intentos, ms }` a la respuesta y se anota.
- Funciona en 1280 px (proyector) y es usable a 375 px.

## Criterios de aceptación

- [ ] Manual: después del ataque 1, el bloque atacado y su conexión se ven en rojo.
- [ ] La lista sigue siendo legible con 30 bloques: tiene scroll y no se rompe.
