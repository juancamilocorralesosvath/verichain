# H10.2 — Cadena como bloques conectados y minado animado

## Especificación

- La página Cadena se muestra como bloques conectados (tarjetas unidas por flechas) con: índice, `hash_anterior` → `hash_cadena`, nonce, firmante y estado.
- Después de verificar, cada bloque se colorea por su estado, y la conexión rota se resalta en rojo.
- Al crear un bloque, una animación o indicador de "minando…" muestra el nonce y el tiempo. Los datos vienen de la respuesta de confirmar; si hace falta, la API agrega `{ intentos, ms }` a la respuesta y se anota.
- Funciona en 1280 px (proyector) y es usable a 375 px.

## Criterios de aceptación

- [x] Manual: después del ataque 1, el bloque atacado y su conexión se ven en rojo.
- [x] La lista sigue siendo legible con 30 bloques: tiene scroll y no se rompe.

## Notas de traspaso

### Decisiones tomadas

- Cadena es una `<ol>` de tarjetas (`<article data-bloque>`) unidas por conexiones (`data-conexion=N`, hacia el bloque N) dentro de una región con scroll (70 vh, enfocable). Probado con 30 bloques.
- Botón **Verificar cadena** (solo admin y auditor; el registrador recibiría 403). Cada bloque queda `ok`/`falla` (falla si cualquiera de sus chequeos falla; `no aplica` no cuenta) y, si ningún bloque falla pero el sello sí (truncamiento), un aviso lo dice.
- Conexión **rota** (`data-roto`) = el chequeo `enlace` del bloque falla. Conexiones **afectadas** (`data-afectada`) = las que tocan a un bloque en falla (así, tras el ataque 1, el bloque atacado y sus conexiones se ven en rojo aunque el enlace de hash no se rompa).
- API: `anexarBloqueTx` (y por tanto `POST /bloques/confirmar`) ahora devuelve además `nonce`, `intentos` y `ms` (de `minar`). Cambio solo aditivo; no toca formatos de hash ni de exportación. Prueba en `bloques.e2e.test.ts`.
- Personas muestra "Minando el bloque…" mientras confirma y luego "Bloque N anexado: nonce X, Y intentos, Z ms". El minado real es muy rápido con la dificultad de demo, así que el indicador se verá solo un instante; con `POW_DIFFICULTY` mayor se aprecia.
- Probado con la API y la web reales: 4 bloques firmados, ataque 1 sobre el bloque 2, Verificar cadena → bloque 2 y sus conexiones en rojo.
- La historia H7.1 (otra sesión) edita `bloques.service.ts`; este PR no lo toca.
