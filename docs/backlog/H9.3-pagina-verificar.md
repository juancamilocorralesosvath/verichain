# H9.3 — Página Verificar

## Especificación

- Botón "Verificar integridad" → `GET /api/cadena/verificar`.
- Componente reutilizable `<ReporteVerificacion reporte={...} />`. Lo reutiliza H8.2.
  - Veredicto global grande (✅ íntegra / ❌ comprometida) y el primer bloque roto.
  - Por bloque, los 5 chequeos con un estado `ok` / `falla` / `no-aplica` y sus motivos.
  - Sección aparte para el sello del servidor.
- Los bloques con falla quedan visibles sin hacer scroll: se resalta el primero roto y hay un enlace para ir a él.
