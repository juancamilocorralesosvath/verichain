# H8.2 — Página de verificación local en el navegador

## Contexto

Diseño §5.9. Lo mismo que el CLI, pero en la web y **sin llamar a la API**.

## Especificación

- La ruta `/verificador` es accesible **sin login**: es justamente la idea de no depender del servidor.
- El usuario sube dos archivos (`cadena.json` y `server-public.pem`). Se verifica con `@bc/core` + un `VerificadorFirma` de WebCrypto: `importKey('spki', ..., { name: 'ECDSA', namedCurve: 'P-256' })` y `verify({ name: 'ECDSA', hash: 'SHA-256' }, ...)`.
- Muestra el reporte con el mismo componente de H9.3 (reutilízalo) y la advertencia de huella si no coinciden.
- Una prueba o comprobación demuestra que no se hace ningún `fetch` durante la verificación.

## Criterios de aceptación

- [ ] Prueba: el `VerificadorFirma` de WebCrypto acepta una firma hecha con `node:crypto` (P1363) y rechaza una alterada.
- [ ] Manual: los fixtures de H8.1 dan el mismo veredicto en la web que en el CLI.

npm run test -w @bc/web && npm run check
