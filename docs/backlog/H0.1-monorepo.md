# H0.1 — Monorepo con workspaces

## Contexto

Diseño §3. Base de todo el repo.

## Objetivo

Monorepo npm con `packages/core` funcionando (build + test), TypeScript estricto, ESLint y Prettier, y scripts raíz.

## Criterios de aceptación

- [x] `npm run check` pasa en limpio.
- [x] `npm run build -w @bc/core` genera `packages/core/dist`.
- [x] TypeScript fijado en `~6.0` (typescript-eslint no soporta TS 7).

## Notas de traspaso

### Decisiones tomadas

- `@bc/core` es ESM (`"type": "module"`). La API Nest (CommonJS) lo puede cargar con `require(esm)`, disponible por defecto desde Node 22.12.
- `npm audit` reporta `minimatch` (moderada) en herramientas de lint (solo desarrollo). Se acepta y se documenta en el informe (H12.2).
- `apps/api`, `apps/web` y `tools/verificador` solo tienen un README. Los crean H2.1, H9.1 y H8.1.
